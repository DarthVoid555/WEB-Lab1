## Описание проекта
Сайт-визитка с динамическим поведением на jQuery и стилями на Sass (SCSS). 
Реализован в рамках лабораторных работ №1–3.

## Технологии
- HTML5
- Sass (SCSS) - модули, миксины, функции, карты
- jQuery 3.7
- Node.js / npm (сборка)
- Font Awesome, Google Fonts

## Что реализовано
- Модульная структура: `utils/`, `base/`, `layout/`, `components/`, `themes/`
- Только `@use` / `@forward`
- Карты, функции (`rem()`, `bp()`), миксины (`respond-to`, `flex-center`, `visually-hidden`)
- БЭМ-именование классов
- Отдельные `js-` селекторы для скриптов
- Светлая / тёмная темы через карты Sass → CSS-переменные (`@each`)
- Переключатель темы с сохранением в `localStorage`
- Компонент `.button` с состояниями и модификаторами

  
## Запуск проекта с нуля

1. Установить зависимости
npm install

2. Собрать CSS (одноразово)
npm run build

3. ИЛИ запустить режим разработки (автопересборка)
npm run sass:dev
