## Описание
To-Do приложение на Vue 3, Vite и Tailwind CSS. 

## Где применены watch и v-if (объяснение)
1. **watch в App.vue**: Используется для реактивного сохранения массива задач в localStorage. При любом изменении (добавление, удаление, переключение статуса) watch с параметром deep: true отслеживает изменения и перезаписывает данные в хранилище.
2. **v-if в App.vue**: Применён для условного рендеринга модального окна. Это позволяет создавать DOM-элементы окна только в момент его открытия, что облегчает управление фокусом.

## Установка и запуск
1. npm ci - установка зависимостей.
2. npm run dev - запуск сервера для разработки.
3. npm run build - сборка проекта в папку dist/.
4. npm run preview - предпросмотр собранной версии.
